# Estudos de SQL com MySQL

Repositório de exercícios práticos desenvolvidos durante meus estudos de SQL e MySQL, com foco em consultas, modelagem relacional e gerenciamento de usuários e permissões.

## 📚 Exercícios

### 1. Consultas SQL — Sakila
Utilização do banco de dados de exemplo Sakila para praticar:
- Subqueries e filtros
- Funções de agregação e manipulação de strings
- Consultas em tabelas relacionadas
- Criação de views

### 2. Banco de Dados de Veículos
Criação de um banco de dados relacional simples, envolvendo:
- Criação de tabelas com `CREATE TABLE`
- Chaves primárias e estrangeiras
- Relacionamentos entre tabelas
- Inserção de registros com `INSERT INTO`

### 3. Usuários e Privilégios
Exercícios de administração do MySQL:
- Criação e exclusão de usuários
- Concessão de permissões com `GRANT`
- Revogação de permissões com `REVOKE`
- Consulta de privilégios com `SHOW GRANTS`

## 🛠️ Tecnologias
- MySQL
- MySQL Workbench
- SQL

## 🎯 Objetivo

Consolidar conhecimentos fundamentais de SQL e bancos de dados relacionais como parte da minha transição de carreira para a área de Dados.
